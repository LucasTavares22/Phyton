#  Projetos em Python — Do Básico ao Avançado

Repositório dedicado à minha jornada prática de aprendizado em **Python**, evoluindo do nível iniciante até conceitos mais avançados, com foco em:

*  Lógica de programação
*  Fundamentos de cibersegurança
*  Manipulação e persistência de dados
*  Automação e boas práticas
*  Evolução contínua como desenvolvedor

---

##  Objetivo

Este repositório documenta minha evolução real em Python através de projetos práticos.
A proposta é **aprender construindo**, aplicando conceitos progressivamente mais complexos.

Cada projeto representa um degrau de conhecimento.

---

##  Estrutura do Repositório

```
python-projetos/
├── basico/
├── intermediario/
├── avancado/
└── desafios/
```

###  Básico

Projetos focados em fundamentos da linguagem:

* Entrada e saída de dados (`input`, `print`)
* Estruturas condicionais (`if`, `elif`, `else`)
* Laços de repetição (`while`, `for`)
* Operadores lógicos
* Primeiros sistemas interativos

**Exemplos:**

* Sistema de login simples
* Calculadoras básicas
* Exercícios de lógica

---

###  Intermediário

Projetos com maior organização e manipulação de dados:

* Listas, tuplas e dicionários
* Validação de dados
* Funções
* Tratamento de erros (`try/except`)
* Integração inicial com SQL

**Exemplos:**

* Sistema de login com múltiplos usuários
* Manipulação de arquivos
* Pequenos sistemas CRUD

---

###  Avançado

Projetos com foco mais próximo do mercado:

* Integração com banco de dados
* Automação com Python
* Estruturação de projetos
* Boas práticas de código
* Conceitos iniciais de segurança

**Exemplos futuros:**

* Sistema de autenticação com banco de dados
* Scripts de automação
* Análise de dados básica
* Ferramentas voltadas para cibersegurança
